## Download and install

Download **Clockify-Bar-VERSION-macOS-universal.zip** from the assets below. This contains the ready-to-run app for **Apple Silicon and Intel Macs running macOS 13 or later**. The source-code archives are for developers.

1. Unzip the download and drag **Clockify Bar.app** into **Applications**.
2. Open the app. It appears in the menu bar, not the Dock.
3. If macOS blocks the first launch, open **System Settings → Privacy & Security → Open Anyway**, then confirm. These builds are ad-hoc signed, not Apple Developer ID signed or notarized. Only approve the download if you trust this repository. See [Apple’s instructions](https://support.apple.com/en-us/102445).
4. Enter your Clockify API key from [Clockify profile settings](https://app.clockify.me/user/settings). The key is stored in your macOS Keychain.

When updating, quit Clockify Bar before replacing the app. Quitting does not stop a Clockify timer. Your existing workspace preference and Keychain credential are retained; macOS may ask for Keychain access again after an update.

`SHA256SUMS.txt` contains the download checksum. Full usage and troubleshooting instructions are in the repository README.
